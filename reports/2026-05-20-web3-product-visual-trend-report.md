# Web3 竞品产品与视觉趋势日报 - 2026-05-20

## 今日核心判断

- **视觉风格变化结论（相对上一期）**：头部交易所的活动视觉继续从“促销海报”向“产品化运营模块”迁移，但今天出现两个更明确的分流：
  1) **AI/工具型产品**（Bot/Wallet/衍生品）更像“教程与控制台”，以步骤条、模块卡片、策略/任务面板来表达可信度与可执行性；
  2) **节点型品牌日/联名赛事**回到更情绪化的节日 KV（如 Pizza Day、网球赛事），用于拉新与社交传播。
- **产品逻辑变化结论（相对上一期）**：从“任务路径化”进一步升级为“**点数化/资格化 + 产品使用**”的组合：用积分/点数/阶段解锁把用户行为（入金、交易、使用 Bot/Wallet）变成可追踪的成长体系，奖励不再只是一次性发放，而是和持续使用强绑定。
- **对 MEXC 的一句话建议**：把 Launchpad/Launchpool/Earn/任务中心统一升级为“可累计的成长体系”，视觉上用“路径 + 模块化卡片 + 资格/点数”表达长期价值，同时为节日节点保留一套更轻、更可社媒传播的 KV 语法。

## 相对上一期变化

- **新增趋势**
  - **“点数化/资格化”成为关键运营骨架**：Binance 把 Wallet 永续与 Alpha Task Points 绑定，出现更明确的“产品入口 + 点数成长 + 兑换/奖励”结构（比上一期更强信号）。
  - **AI 进入“可操作步骤”而不是概念**：OKX 在 Bot 活动页直接给出“连接 Claude 等 AI → 生成策略指令 → 启动 Bot”的执行路径，AI 从“赛博概念”变成“使用说明书”。
- **强化趋势**
  - **活动页继续产品化**：越来越像功能介绍页（步骤、模块、FAQ、风险提示、资格门槛），而不是单张促销 KV。
  - **奖励表达更偏“权益包/阶段解锁”**：从单一奖池数字，转向多档奖励、任务包、资格/里程碑。
- **减弱趋势**
  - 纯“奖池数字 + 金币炫光”仍在，但在主流头部的关键入口页上占比继续下降；更多退回到社媒 KV 或次级物料。
- **反转或需要修正的判断**
  - 上一期开到 Binance 的直接证据偏少；今天可确认 Binance 已把“Wallet + 永续交易 + 点数活动”作为明确增长抓手，应纳入主线观察。
- **持续观察但尚未确认的信号**
  - Gate.io 类“极高 APR 的新客 Mint/理财奖励”仍在高频迭代（Round/Season 机制），但其是否会进一步被包装成更长期的产品体系（而不是周期促销）需要继续观察。

## 重点发现（最多 6 条）

### 1) Binance：Wallet 永续 + Alpha Task Points，把“自托管入口”做成增长主线

- 竞品：Binance
- 证据链接：https://www.binance.com/da-DK/support/announcement/detail/258767f4577644398fcf3f660a1f4098
- 来源等级：一级证据（官方公告）
- 产品逻辑判断：用 **Wallet 永续合约**做“功能入口”，用 **Alpha Task Points**做“成长/资格”机制，典型是“进入产品 → 完成任务/交易行为 → 获得点数/奖励”。这比传统 Launchpool/交易赛更像可持续的产品运营框架。
- 视觉风格判断：更适合“产品说明 + 任务系统 UI”的视觉：步骤、模块卡片、权益与规则层级清晰；奖励不需要靠大金光放大，而靠“路径可理解”建立转化。
- 对 MEXC 的启发：MEXC 如果要把 Web3 Wallet、Earn、Bot 拉到增长主线，建议引入“点数/资格”统一底座，让用户能累计与复用；视觉上突出“你现在在第几步、下一步拿什么权益”。
- 置信度：高

## 视觉风格变化

- **色彩与质感**：
  - 工具型/产品型页面更偏“低噪音、信息可读、模块化”，即使在深色底上也减少过度炫光；
  - 节日/赛事节点（Pizza Day、网球赛事）回到更“情绪化、节庆符号、联名资产”的表达。
- **KV 与版式结构**：
  - 头部入口页继续从“中心大标题”转向“标题 + 关键利益点 + 模块卡片 + 步骤/路径 + CTA”。
- **高频视觉元素**：
  - 步骤条、任务面板、权益卡片、APR/收益指标、倒计时、token logo、资格/点数。
- **标题层级与利益点表达**：
  - 从“Win X USDT”进一步转向“完成路径/满足资格/解锁权益”的叙事；利益点更像产品说明而不是口号。
- **品牌资产使用方式**：
  - Coinbase 代表的“强品牌一致性 + 低噪音信任感”继续成立；
  - OKX/Bitget 等更依赖“模块化组件与产品 UI 语言”沉淀资产；
  - Bybit 在节点活动上更偏“联名/赛事化图形资产”。

## 产品逻辑变化

- **主推产品方向**：
  - Wallet/衍生品入口（Binance Wallet 永续）、Trading Bot（OKX）、会员权益（Coinbase One）、Launchpool/质押（Bitget）、上新任务（KuCoin）。
- **用户转化路径**：
  - “看见奖池 → 参与”继续弱化；“理解资格/点数 → 按步骤完成 → 使用产品 → 领取/累计权益”继续强化。
- **激励机制**：
  - 从一次性奖励转向“点数/资格/阶段解锁 + 多档权益包”。
- **活动机制**：
  - 交易赛被“赛事化叙事”包装（Bybit），但在转化页上仍回到规则/资格/阶段；
  - 高 APR 新客活动（Gate.io）仍是拉新手段，但更需要产品化叙事来降低不信任感。
- **功能包装方式**：
  - AI 不再只是概念：开始作为“策略生成/指导”被写入步骤，成为产品的一部分（OKX）。

## 视觉变化与产品逻辑变化的关系

- 当产品目标从“冲动参与”转向“持续使用/留存”时，视觉自然从“刺激型海报”转向“解释型页面”：需要让用户看懂资格、步骤、时间、收益与风险。
- 当增长依赖“点数/资格/阶段解锁”时，视觉必须提供**状态感**（你在哪一步、还差什么、完成后得到什么），否则点数体系会被感知为黑箱。
- 当引入 AI 降低门槛时，视觉需要把 AI 拟人化的“酷感”让位给“可执行性与安全感”（提示、限制、风险提示、示例输出）。
- 节日/赛事节点的情绪化 KV 仍有价值，但它更适合做“入口引流与社媒传播”，最终转化仍要落回产品化页面。

## MEXC 可跟进方向（5 条可执行建议）

1. **建立统一的“点数/资格”成长底座**：把 Launchpad/Launchpool/Earn/任务中心打通成可累计体系；视觉上固定三件套：进度（step/stage）、资格条件（checklist）、权益包（reward cards）。
2. **为三类产品建立三套视觉语法**：
   - Wallet/衍生品：步骤化教程 + 风险提示模块 + 关键能力卡片；
   - Bot/策略：策略卡片 + 一键启用 + 结果/风险预期；
   - Earn/质押：收益结构图 + 期限/流动性标签 + 明确的限制条件。
3. **节点活动做“双层物料结构”**：社媒/站内 Banner 用情绪 KV 拉新；落地页必须产品化（路径/资格/FAQ/风险），避免只靠奖池数字。
4. **把“项目身份叙事”嵌进上新活动模板**：除 token logo 外补齐“项目类别/应用场景/用户角色”，让设计能在同模板里做差异化。
5. **强化“可信表达”**：把限制条件、风险提示、规则解释做成可复用模块（而不是长段文字），用版式层级减少不信任感，尤其是在高收益/高奖励活动中。

## 风险与不建议跟进方向

- **不建议继续把差异化押在奖池数字**：行业模板化严重，投入产出比下降且极易同质化。
- **不建议把 AI 只当赛博视觉概念**：OKX 已进入“可执行步骤”；如果没有真实功能支撑，容易被用户识别为噱头。
- **不建议把高收益（如 100% APR）当作纯促销口号**：需要配套更强的可信表达（限制、期限、风险、适用人群）与更克制的视觉语气，否则会拉高不信任与监管/舆情风险。
