# Web3 竞品产品与视觉趋势日报 - 2026-05-19

## 今日核心判断

- 视觉风格变化结论：头部交易所的活动视觉正在从单纯“奖池数字 + 炫光促销”转向“产品场景化包装”。Web3 Wallet、Trading Bot、Membership、Launchpool 这些产品被包装成可持续使用的功能入口，KV 仍保留奖励刺激，但页面文案更强调任务路径、资格、权益和连续参与。
- 产品逻辑变化结论：竞品正在把活动从一次性领取奖励，升级成“功能使用任务 + 资产留存 + 连续行为”的组合。典型路径是：注册/订阅/入金 -> 使用产品功能 -> 形成交易量或锁仓 -> 领取奖励/积分/资格。
- 对 MEXC 的一句话建议：MEXC 的活动视觉不要只放大“奖池”和“空投”，应该把 Launchpad、Launchpool、Earn、任务中心包装成更清晰的产品增长体系，让用户看懂“为什么参与”和“参与后会留下什么”。

## 重点发现

### 1. OKX 正在把交易机器人包装成“轻娱乐化任务产品”

- 证据链接：[OKX Play and Earn with Trading Bots Season 9](https://www.okx.com/campaigns/bot-ninth)
- 产品逻辑判断：OKX 把 Trading Bot 活动设计成任务包，而不是单纯交易赛。奖励包含 Futures Grid Bot Airdrop Position、Loss Coverage Voucher、USDT 等，用户需要围绕 Bot 建仓、入金、任务完成来获得权益。
- 视觉风格判断：这类页面适合使用“游戏关卡 / 任务面板 / 奖励卡片”的 UI 化视觉，而不是传统金融长表格。标题应突出“Play and Earn”，副标题解释奖励路径。
- MEXC 启发：如果 MEXC 做 Bot 或策略类产品，应把“自动化交易能力”视觉化成任务地图或策略卡片，减少用户对复杂交易工具的心理门槛。

### 2. OKX Web3 Wallet 开始把 AI Agent 作为活动机制，而不是单纯概念传播

- 证据链接：[OKX Agentic Trading Contest](https://web3.okx.com/boost/trading-competition/agentic-trading)
- 产品逻辑判断：OKX 把 Agentic Wallet、DEX、交易赛绑定起来，强调“用 AI agent 执行交易”的场景。活动机制已经从人工交易排行转向代理执行、链上交互和责任边界。
- 视觉风格判断：这类产品更适合赛博、链路节点、Agent 控制台、数据流视觉，而不是金币奖杯类传统活动图。
- MEXC 启发：MEXC 如果跟 AI Agent，不宜只做“AI”字样包装；应结合实际功能入口，例如策略执行、智能提醒、任务代理，视觉上用“操作台 + 风险提示 + 自动化流程”建立可信感。

### 3. Coinbase 用会员体系把促销做成“月度权益节”

- 证据链接：[Coinbase One Member Month](https://help.coinbase.com/en/coinbase/other-topics/coinbase-one/member-month?query=chat)
- 产品逻辑判断：Coinbase 不是以币种上新为核心，而是以 Coinbase One 会员权益为核心，设计了年费折扣、Bitcoin Card、连续任务、Prediction Markets、资产转入奖励等权益组合。
- 视觉风格判断：Coinbase 适合低噪音、高信任的会员权益视觉：清晰表格、权益卡片、品牌蓝、生活方式权益，而不是强促销 KV。
- MEXC 启发：MEXC 可以考虑把零散活动沉淀成“会员权益月 / 新用户成长月 / 资产增值月”这类系列化活动，视觉上更像产品品牌，而不是每日促销。

### 4. MEXC 当前 Launchpad / Launchpool 仍然是强奖励、强订阅、强任务逻辑

- 证据链接：[MEXC SPACEX(PRE) Launchpad](https://www.mexc.fm/announcements/article/spacex-pre-launchpad-17827791535416)
- 证据链接：[MEXC EMBLEM Launchpool](https://blog.mexc.com/mexc-launch-emblem-launchpool-5000000-airdrop-rewards/)
- 产品逻辑判断：MEXC 的优势是规则清晰、奖励明确，SPACEX(PRE) 页面强调订阅池、新用户池、USD1 池、KYC、净入金、现货/合约交易任务；EMBLEM Launchpool 强调多池锁仓和空投奖励。
- 视觉风格判断：这类视觉天然容易走向“大数字 + token logo + 奖池卡片”。风险是和 Bitget、Gate、KuCoin 的 Launchpool / Airdrop 模式高度同质。
- MEXC 启发：应强化“为什么这个项目值得参与”的品牌叙事，比如项目类别、场景、用户身份，而不是只强化池子和金额。

### 5. Bitget、KuCoin、Gate 的活动仍以奖池和文化/场景绑定为主

- 证据链接：[Bitget KAIO Launchpool](https://www.bitget.com/asia/support/articles/12560603883519)
- 证据链接：[KuCoin PROOF: Tomorrowland Edition](https://financefeeds.com/kucoin-proof-tomorrowland-edition-adds-500k-usdt-pool/)
- 证据链接：[Gate GUSD Minting Promotion Season 12](https://miniapp.gate.com/blog/gate-gusd-minting-promotion-season-12-earn-100-percent-apy-with-multiple-wealth-management-rewards)
- 产品逻辑判断：Bitget 继续押 Launchpool + 平台币/稳定币锁仓，KuCoin 用 Tomorrowland 把交易赛包装成文化事件，Gate 用 GUSD 100% APY 把收益产品包装成新用户理财入口。
- 视觉风格判断：Bitget 更偏平台币生态奖池；KuCoin 有机会用音乐节、舞台、票务、年轻文化做差异化；Gate 更偏收益率数字和财富管理感。
- MEXC 启发：MEXC 可以避开单纯奖池竞争，尝试把活动与明确用户场景绑定，例如“新币发现者”“早期项目订阅者”“资产增值计划”。

## 视觉风格变化

- 色彩与质感：行业仍大量使用黑金、蓝紫科技、霓虹渐变、金色奖励元素，但 Coinbase 类会员产品更偏清爽、低噪音、信任感。
- KV 和版式结构：从单一中心大标题，转向“标题 + 奖励卡片 + 任务路径 + CTA”的产品化结构。活动页越来越像功能页面，而不是单张海报。
- 高频视觉元素：奖池数字、token logo、金币、卡片、排行榜、任务清单、钱包、Bot/Agent、收益率数字。
- 标题层级和利益点表达：高频表达从“Win X USDT”扩展到“Complete task / Subscribe / Lock / Earn / Boost limit / Member reward”。说明竞品更重视用户行为路径。
- 品牌资产使用方式：强品牌色仍重要，但单纯色块已经不够；竞品开始用产品模块和活动机制塑造品牌资产，例如 OKX Boost、Coinbase One、KuCoin PROOF。

## 产品逻辑变化

- 主推产品方向：Web3 Wallet、Trading Bot、Launchpool/Launchpad、会员权益、Earn/收益类产品。
- 用户转化路径：从“看见奖池 -> 参与活动”变成“理解权益 -> 完成任务 -> 使用功能 -> 形成资产/交易留存”。
- 激励机制：锁仓、订阅、入金、连续行为、交易量、积分、会员权益混合使用。
- 活动机制：交易赛仍在，但更常被包装为产品功能教育，例如 Bot 任务、AI Agent 交易、钱包 DEX 使用。
- 功能包装方式：越来越强调“入口”和“场景”：钱包不只是钱包，是交易/Agent/DEX 入口；会员不只是订阅，是权益中心；Launchpool 不只是空投，是新币发现机制。

## MEXC 可跟进方向

1. 把 Launchpad / Launchpool 统一包装成“新资产发现体系”，建立固定视觉模板：项目身份、参与路径、收益机制、风险提示四块清晰分层。
2. 做“任务路径型 KV”：不要只放奖池金额，而是把 Deposit / Trade / Subscribe / Boost / Claim 画成流程，降低理解成本。
3. 为 Bot、Earn、Wallet 类产品建立不同视觉语法：Bot 用策略卡片和自动化流程；Earn 用稳健收益和资产层级；Wallet 用链上路径和安全感。
4. 增加系列化活动品牌，例如“Discovery Week”“MEXC Alpha Month”“New Asset Sprint”，减少每天换皮海报感。
5. 报告和设计复盘中增加“产品逻辑标签”：奖励驱动、功能教育、资产留存、会员权益、文化合作，帮助设计团队判断 KV 应该怎么表达。

## 风险与不建议跟进方向

- 不建议继续只堆奖池数字。Bitget、Gate、KuCoin 都在做，MEXC 如果只比金额，会陷入同质化。
- 不建议把 AI Agent 只当视觉概念。OKX 的强点是把 Agent 放进交易机制，MEXC 如果没有实际功能支撑，容易显得空泛。
- 不建议所有活动都用黑金/赛博/金币。Web3 Wallet、会员、Earn、Bot 应该有不同的视觉语言。
- 不建议报告里保存过多图片。每天 3-8 张关键证据足够，重点是判断，而不是素材堆积。
